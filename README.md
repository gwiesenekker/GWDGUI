# GWDGUI
A hub GUI for GWD, generated by Codex without me writing a single line of GUI code. It includes Windows-specific workarounds for dialog boxes. The Windows engine communication issue was solved by having Codex port GWD's existing C code for launching the engine and connecting stdin/stdout.

Current release: [Version 3.2](https://github.com/gwiesenekker/GWDGUI/releases/tag/v3.2) — October 27, 2026.

See [Change history](CHANGELOG.md) for fixes and validation results.

Build on Linux with Lazarus/LCL (GTK2), FPC and Python 3 installed:

```sh
bash build.sh
```

The build uses a temporary output directory and replaces the local executable
only after compilation succeeds. Run `./gwdgui` from this directory. This is a
portable application: keep its directory writable for preferences, engine
configuration and output files. Those local files are not published to GitHub.

For a native Windows Lazarus build, open `gwdgui.lpi`, select the **Windows**
build mode (Project → Project Options → Build modes), and choose **Build**.
This embeds the manual and current Git commit without Python. Install Git for
Windows and ensure `git` is available on PATH before starting Lazarus. Build
from a Git checkout (or a copy including `.git`) for commit identification;
a source ZIP without Git metadata reports the commit as unavailable. Keep
`draughts.ttf` beside `gwdgui.exe`.

Run `bash tests/run_regression_checks.sh` for the headless checks (requires FPC, Python 3
and ripgrep); the GUI and tournament checks also require Lazarus/GTK2 and a display.
See [the response to Claude's latest review](REVIEW_NOTES.md) for decisions and
remaining limitations.
